Pixelverse makes images of a character you describe and records narration of what you type, using your own OpenAI and ElevenLabs accounts. This page covers setting it up and what to do when something goes wrong.

Need help? Write to johnpederson@mrpxls.com. Say what you tapped and the exact words of any message the app showed. Please do not send your API keys.

Getting started

Why does it ask for API keys?

Pixelverse does not sell images or narration. OpenAI makes the images and ElevenLabs records the narration, each through an account you hold with them. An API key is how the app uses your account. Pixelverse itself is free and has no purchases inside it.

Getting an OpenAI key

  1. In Pixelverse, open Settings and tap Open OpenAI's API Keys Page.
  2. Sign in on OpenAI's API site and set up billing there.
  3. Create a new secret key and copy it straight away. OpenAI shows a key only once.
  4. Back in Pixelverse, paste it under OpenAI and tap Save Key.

OpenAI's API is billed separately from ChatGPT. A ChatGPT subscription does not include it.

Getting an ElevenLabs key

  1. In Settings, tap Open ElevenLabs's API Keys Page.
  2. Sign in to ElevenLabs and create a key in your account settings. If you limit what the key can do, give it access to Text to Speech.
  3. Paste it under Rant Narration and tap Save Key.

You only need the key for the part you use. Images need the OpenAI key; narration needs the ElevenLabs key.

Costs

What does it cost?

Pixelverse charges nothing. OpenAI and ElevenLabs bill your accounts for each image and each recording, at their own prices. Every button that sends a paid request says so beside it: Generate, Generate Portrait, Save & Record Narration, Record Narration, and Re-record.

I cancelled, or the request failed. Was I charged?

Possibly. A request that was already sent when you cancelled, or when the app was closed, may still be billed by the company that received it. Their billing pages show what was charged.

When something goes wrong

"The saved API key was rejected."

The company did not accept the key. Check that you copied all of it, that it has not been revoked, and that it is in the right place: the OpenAI key under OpenAI, the ElevenLabs key under Rant Narration. Saving a new key replaces the old one.

A message about access to the selected model

Your OpenAI account may not have access to the image model you chose. In Settings, Check Flare & Sunburst Access tests this without generating or charging for an image. Try the other model on the Create screen, or check your account with OpenAI.

"No OpenAI key is saved" or "No ElevenLabs key is saved"

Add the key in Settings. Create and Rants show a reminder at the top while the key they need is missing.

The request stopped when I locked my iPhone

If the iPhone locks or you leave the app while a request is running, iOS gives the app about half a minute to finish. A longer request is cancelled. Keep Pixelverse open and the iPhone awake until the image or recording appears.

The image appeared but would not save

If saving to the library fails, the image stays on the Create screen with a Retry Library Save button. Free up some storage and tap it.

Your library

Where are my images and recordings?

On your iPhone, inside the app. Nothing is kept on a server. Use the share sheet on any image, recording, or rant to send it elsewhere or save an image to Photos.

Backing up and moving to a new iPhone

  1. In Settings, tap Back Up Library… and save the folder somewhere in Files, such as iCloud Drive.
  2. On the other iPhone, tap Restore from Backup…, open the backup folder itself so that library.json is on screen, and tap Open.
  3. Pixelverse shows what the backup holds and what it will replace. Tap Replace to go ahead.

Restoring replaces the whole library; it does not merge. A backup never contains your API keys, so enter those again.

Deleting things

Deleting an image, a rant, a reference, or a character removes its files from the iPhone and cannot be undone. Deleting the app deletes the whole library, so back it up first if you want to keep it.

Removing a key

In Settings, Remove Key… appears under a saved key. It deletes the key from the iPhone. To cancel the key itself, revoke it on the company's website.

Other questions

Does it work on iPad?

Pixelverse is made for iPhone. On an iPad it runs in an iPhone-sized window.

What does the app send, and to whom?

See the privacy policy. The same summary is in the app under Settings, What Pixelverse Sends.
